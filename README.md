# bharatpin-3d
India-first 3D navigation, hybrid satellite map, and official 10-character DIGIPIN Progressive Web App built with MapLibre GL JS and zero paid API keys



**BharatPin 3D** is a mobile-first Indian navigation, hybrid satellite, and digital addressing Progressive Web App (PWA) combining Mappls-style Indian utilities with Google Maps-inspired 3D exploration—built with **zero paid API keys**.

## Key Features
- **3D Buildings & Terrain:** Extruded 3D buildings, directional lighting, Hillshade terrain mode, and bilingual (English + Hindi) locality and road labels over OpenFreeMap vector tiles and ESRI World Imagery satellite tiles.
- **Official 10-Character DIGIPIN:** Offline 4×4 spiral grid encoder and decoder (`XXX-XXX-XXXX`) with instant copy, shareable `?pin=` URLs, and QR code generation.
- **BharatPin Geotag Camera:** Stamp photos or live map views with official DIGIPIN coordinates, IST timestamp, address, and QR matrix, and export as PNG.
- **Multimodal Routing & Trip Cost Estimator (`₹`):** Car, Bike, Truck, Walk, and Metro/Bus routing via OSRM with live fuel (`Petrol`, `Diesel`, `CNG`, `EV`) and NHAI highway toll estimates.
- **Turn-by-Turn Navigation HUD:** Active GPS tracking, Simulate Drive mode, 3D Junction View preview, live speedometer, crowdsourced road safety alerts, and English/Hinglish voice guidance.
- **Live Telemetry & Local Discovery:** Real-time Open-Meteo weather and NAQI air quality, fast Photon nearby POI chips (`Restaurants`, `Petrol`, `Hotels`, `Hospital`, `ATM`, `Station`), distance ruler, and saved `Home`/`Work` presets.

## Tech Stack
- **Map Engine:** MapLibre GL JS (`v4.7.1`)
- **Vector & Satellite Tiles:** OpenFreeMap & ESRI World Imagery
- **Search, Routing & Weather:** Nominatim, Photon API, OSRM, Open-Meteo, Wikipedia/Wikimedia APIs
